# 待办清单整理流程

## 需要什么材料

用户指定一份文字记录（.txt 或 .md）。没有指定时先询问，不要猜。

## 按什么步骤做

1. 读取记录，把内容分成两组：“准备放进清单的事项”和“不放进清单的内容”（已经完成的状态、统计数字）。在对话中列出这两组，等用户确认后再继续。这一步不创建任何文件。
2. 用户确认后，生成待办清单。每条写序号、事项、负责人和截止时间。负责人和时间沿用原文的写法，原文没有写明的写“待确认”。事项要保留影响执行的细节，例如数量和对象。
3. 保存到记录所在的文件夹，文件名为“原文件名-待办清单.txt”。同名文件已经存在时，先告诉用户，不覆盖。
4. 保存后重新读取文件，逐条与原文核对事项、负责人、时间和细节。

## 产出与边界

完成后报告：文件位置、待办条数、仍为“待确认”的内容。

- 不修改原始记录；
- 不补充原文没有的负责人、日期或任务；
- 不把“周四下班前”这类说法换算成具体日期或时刻。
