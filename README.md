# 《Codex 从零入门实战》配套资源

这里是《Codex 从零入门实战》的配套资源，包括练习文件、全书提示词、参考结果、案例成品和 Skill 示例。书中的人名、单位和数据均为虚构的教学材料。

## 下载

**[单击这里下载全部配套资源（ZIP 压缩包，约 357 KB）](https://github.com/madgiraffe1/codex-from-zero/releases/latest/download/codex-book-resources.zip)**

不需要注册账号，也不需要安装其他软件。下载后先解压，不要只在压缩包的预览窗口里打开：

- Windows：右击压缩包，选择“全部解压缩”。
- macOS：双击压缩包。

解压后会得到“配套资源”文件夹，接下来按书中1.4.3节操作。

## 里面有什么

| 内容 | 用途 |
|---|---|
| 全书提示词.txt | 按章节收录书中要发送给 Codex 的要求和练习材料，可以直接复制 |
| 练习文件 | 第3、4、7、8、9、11章的练习材料 |
| 参考结果 | 第4章的两份参考结果，只用于对照 |
| 案例成品 | 第9章和第10章完成后的网页项目 |
| Skill示例 | 第11章用到的 3 个 Skill |
| 配套资源说明.txt | 每个文件夹的详细说明 |
